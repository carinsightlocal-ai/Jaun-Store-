How to Install Any Extension in 60s

Simple 4-step developer mode installation for Google Chrome & Brave.

1

Download Free Package (Google Drive)

Click the Download (Drive) button on the extension card in Jaun Store to open the Google Drive folder and download the extension package.

2

Extract / Unzip the Files

Right-click the downloaded .zip file and select Extract All... to any permanent folder on your computer.

3

Open Chrome Extensions Manager

In Google Chrome, type chrome://extensions in the address bar and press Enter.

4

Enable Developer Mode & Load Unpacked

Turn ON the Developer mode toggle switch at the top right, click Load unpacked button at the top left, and select the extracted extension folder!
